# Icoon

Een icoon is een grafisch symbool dat gebruikt wordt als visuele aanvulling bij een tekst, button of functionaliteit.

## Wanneer gebruik je een Icon

Gebruik een icoon als aanvulling bij bijvoorbeeld een label, een button of link om de herkenbaarheid en scanbaarheid te vergroten.

## Anatomie van een Icon

Het component bestaat uit:

- Het symbool.

## Richtlijnen

- Gebruik alleen de Rijkshuisstijl iconen die beschikbaar zijn in ROOS.
- Verschillende gebruikers kunnen een icoon op verschillende manier interpreteren en moet daarom altijd voorzien worden van tekst. 
- Iconen zijn altijd decoratief en worden verborgen voor schermlezers.
