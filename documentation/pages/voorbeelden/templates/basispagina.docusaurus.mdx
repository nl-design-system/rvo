# Basispagina

De Basispagina template is het verplichte fundament voor elke pagina binnen een website of applicatie.

<TemplateLink />

<div className="rvo-margin-block-start--xl">

## Opbouw

Een basispagina bevat minimaal de volgende onderdelen:

<ul className="rvo-ul rvo-ul--icon rvo-ul--no-margin rvo-ul--no-padding">
  <li>Het Header component met daarin het logo.</li>
  <li>Een content vlak met een maximale breedte.</li>
  <li>In het content vlak staat minimaal één heading van het type h1 met de paginatitel.</li>
  <li>Een Footer component met de verplichte onderdelen.</li>
</ul>

</div>
